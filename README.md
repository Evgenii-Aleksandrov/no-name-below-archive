# No Name Below — The Descent Archive

A static development reference and connected Talent Atlas. Serve this directory over HTTP(S); the game engine and catalog exporter are not needed. Asset paths are relative to this directory, including when hosted below a repository path. Hash links preserve the site path.

The Archive is a development preview. The reference uses source-reviewed mechanics and owner-authored lore, not a claimed released game version. Builds are stored in the browser and can be shared through URL fragments.

Website code: LICENSE-CODE.txt. Artwork/content: ARTWORK-AND-CONTENT-NOTICE.md. Font notices remain beside the fonts. See release.json for the source snapshot and transformations.
